```markdown
# Zephyr Language Specification

## Core Idea
A simple, expression-oriented scripting language with first-class functions, immutable data structures (lists, dicts), and error-as-values semantics.

## Design Decisions
- **Errors propagate as values**, not exceptions. `Miss(reason)` is a first-class value.
- **All expressions return values**; statements are just top-level expressions.
- **Newlines separate expressions** (with bracket nesting suppressed inside `()[]`).
- **Strict evaluation**, left-to-right.
- **Immutable data**: lists and dicts are persistent (no mutation).
- **Functions are closures** capturing their defining environment.

## Grammar (precedence, low to high)
```
program    := expr* EOF
expr       := or_expr
or_expr    := and_expr ('or' and_expr)*
and_expr   := comparison ('and' comparison)*
comparison := add_expr (('==' | '!=' | '<' | '<=' | '>' | '>=') add_expr)*
add_expr   := mul_expr (('+' | '-') mul_expr)*
mul_expr   := unary (('*' | '/' | '%') unary)*
unary      := ('not' | '-') unary | postfix
postfix    := primary ('[' expr ']' | '.' NAME)*
primary    := NUMBER | STRING | 'true' | 'false' | 'nil' | NAME
             | '[' expr_list? ']'
             | '{' dict_pair_list? '}'
             | '(' expr ')'
             | 'if' expr '{' expr '}' 'else' '{' expr '}'
             | 'let' NAME '=' expr
             | 'fn' '(' param_list? ')' '{' expr '}'
             | 'print' expr

expr_list  := expr (',' expr)*
dict_pair_list := dict_pair (',' dict_pair)*
dict_pair  := expr ':' expr
param_list := NAME (',' NAME)*
```

## Error Story
- `Miss(reason: str)` represents runtime errors: unbound name, bad index, arity mismatch, div-by-zero, non-bool in condition, etc.
- `missed(x)` predicate returns true if x is a Miss.
- All operations propagate Miss values (operand is Miss ⇒ result is Miss).
- No try/catch; errors just flow through.

## Exit Codes
- 0: successful execution
- 1: runtime error (program produces a Miss value)
- 2: lex or parse error

## Builtins
- `len(list/dict/str)` → int
- `type(x)` → "int" | "float" | "bool" | "nil" | "list" | "dict" | "str" | "fn" | "miss"
- `keys(dict)` → list of keys
- `values(dict)` → list of values
- `range(n)` → list [0, 1, ..., n-1]
- `map(fn, list)` → list with fn applied to each element
- `filter(fn, list)` → list with elements where fn returns true
```

```python
# zeph.py - Zephyr language interpreter
import sys, re
from dataclasses import dataclass
from typing import Any, Optional, Dict, List

# ===== Error Value =====
@dataclass
class Miss:
    reason: str
    def __repr__(self): return f"miss({self.reason!r})"

def missed(x): return isinstance(x, Miss)

# ===== Tokens & Lexer =====
@dataclass
class Token:
    type: str
    value: Any
    line: int
    col: int

def tokenize(src):
    lines = src.split('\n')
    tokens = []
    line_no = 1
    bracket_depth = 0
    
    for line_idx, line in enumerate(lines):
        line_no = line_idx + 1
        col = 0
        while col < len(line):
            # Skip whitespace
            if line[col].isspace():
                col += 1
                continue
            
            # Comments
            if line[col:col+2] == '//':
                break
            
            # Two-char operators first
            two_char = line[col:col+2]
            if two_char in ('==', '!=', '<=', '>='):
                tokens.append(Token(two_char, two_char, line_no, col))
                col += 2
                continue
            
            # Strings
            if line[col] in ('"', "'"):
                quote = line[col]
                col += 1
                start = col
                while col < len(line) and line[col] != quote:
                    if line[col] == '\\': col += 2
                    else: col += 1
                if col >= len(line):
                    return None  # Unterminated string
                value = line[start:col]
                tokens.append(Token('STRING', value, line_no, col-len(value)-1))
                col += 1
                continue
            
            # Numbers
            if line[col].isdigit():
                start = col
                has_dot = False
                while col < len(line) and (line[col].isdigit() or (line[col] == '.' and not has_dot)):
                    if line[col] == '.': has_dot = True
                    col += 1
                num_str = line[start:col]
                try:
                    value = float(num_str) if has_dot else int(num_str)
                except:
                    return None  # Bad number
                tokens.append(Token('NUMBER', value, line_no, start))
                continue
            
            # Identifiers & keywords
            if line[col].isalpha() or line[col] == '_':
                start = col
                while col < len(line) and (line[col].isalnum() or line[col] == '_'):
                    col += 1
                name = line[start:col]
                kw = name
                typ = 'KEYWORD' if name in ('true', 'false', 'nil', 'if', 'else', 'let', 'fn', 'and', 'or', 'not', 'print') else 'NAME'
                tokens.append(Token(typ, name, line_no, start))
                continue
            
            # Single-char operators & punctuation
            ch = line[col]
            if ch in '+-*/%()[]{}:,=<>.':
                if ch in '([': bracket_depth += 1
                elif ch in ')]': bracket_depth -= 1
                tokens.append(Token(ch, ch, line_no, col))
                col += 1
                continue
            
            # Unknown char
            return None
        
        # Newline (only emit if bracket_depth == 0)
        if bracket_depth == 0 and line_idx < len(lines) - 1:
            tokens.append(Token('NEWLINE', '\n', line_no, len(line)))
    
    tokens.append(Token('EOF', None, line_no, len(lines[-1]) if lines else 0))
    return tokens

# ===== AST Nodes =====
def _simple(name, fields):
    return type(name, (), {
        '__init__': lambda self, **kw: [setattr(self, k, kw.get(k)) for k in fields],
        '__repr__': lambda self: f"{name}({', '.join(f'{k}={getattr(self,k)!r}' for k in fields)})",
        'line': 0
    })

Num = _simple('Num', ['value', 'line'])
Str = _simple('Str', ['value', 'line'])
Bool = _simple('Bool', ['value', 'line'])
Nil = _simple('Nil', ['line'])
Name = _simple('Name', ['name', 'line'])
BinOp = _simple('BinOp', ['op', 'left', 'right', 'line'])
UnOp = _simple('UnOp', ['op', 'operand', 'line'])
List = _simple('List', ['elements', 'line'])
Dict = _simple('Dict', ['pairs', 'line'])
Index = _simple('Index', ['obj', 'index', 'line'])
Field = _simple('Field', ['obj', 'field', 'line'])
Call = _simple('Call', ['func', 'args', 'line'])
If = _simple('If', ['cond', 'then_branch', 'else_branch', 'line'])
Let = _simple('Let', ['name', 'value', 'line'])
Fn = _simple('Fn', ['params', 'body', 'line'])
Print = _simple('Print', ['value', 'line'])

# ===== Parser =====
class Parser:
    def __init__(self, tokens):
        self.tokens = tokens
        self.pos = 0
    
    def current(self):
        return self.tokens[self.pos] if self.pos < len(self.tokens) else self.tokens[-1]
    
    def peek(self, offset=1):
        return self.tokens[self.pos + offset] if self.pos + offset < len(self.tokens) else self.tokens[-1]
    
    def advance(self):
        self.pos += 1
    
    def expect(self, typ):
        if self.current().type != typ:
            raise SyntaxError(f"Expected {typ}, got {self.current().type} at {self.current().line}:{self.current().col}")
        tok = self.current()
        self.advance()
        return tok
    
    def skip_newlines(self):
        while self.current().type == 'NEWLINE':
            self.advance()
    
    def parse(self):
        exprs = []
        self.skip_newlines()
        while self.current().type != 'EOF':
            exprs.append(self.expr())
            self.skip_newlines()
        self.expect('EOF')
        return exprs
    
    def expr(self):
        return self.or_expr()
    
    def or_expr(self):
        left = self.and_expr()
        while self.current().type == 'KEYWORD' and self.current().value == 'or':
            op_tok = self.current()
            self.advance()
            right = self.and_expr()
            left = BinOp(op='or', left=left, right=right, line=op_tok.line)
        return left
    
    def and_expr(self):
        left = self.comparison()
        while self.current().type == 'KEYWORD' and self.current().value == 'and':
            op_tok = self.current()
            self.advance()
            right = self.comparison()
            left = BinOp(op='and', left=left, right=right, line=op_tok.line)
        return left
    
    def comparison(self):
        left = self.add_expr()
        while self.current().type in ('==', '!=', '<', '<=', '>', '>='):
            op_tok = self.current()
            self.advance()
            right = self.add_expr()
            left = BinOp(op=op_tok.type, left=left, right=right, line=op_tok.line)
        return left
    
    def add_expr(self):
        left = self.mul_expr()
        while self.current().type in ('+', '-'):
            op_tok = self.current()
            self.advance()
            right = self.mul_expr()
            left = BinOp(op=op_tok.type, left=left, right=right, line=op_tok.line)
        return left
    
    def mul_expr(self):
        left = self.unary()
        while self.current().type in ('*', '/', '%'):
            op_tok = self.current()
            self.advance()
            right = self.unary()
            left = BinOp(op=op_tok.type, left=left, right=right, line=op_tok.line)
        return left
    
    def unary(self):
        if self.current().type == 'KEYWORD' and self.current().value == 'not':
            op_tok = self.current()
            self.advance()
            operand = self.unary()
            return UnOp(op='not', operand=operand, line=op_tok.line)
        if self.current().type == '-':
            op_tok = self.current()
            self.advance()
            operand = self.unary()
            return UnOp(op='-', operand=operand, line=op_tok.line)
        return self.postfix()
    
    def postfix(self):
        node = self.primary()
        while True:
            if self.current().type == '[':
                self.advance()
                index = self.expr()
                idx_tok = self.expect(']')
                node = Index(obj=node, index=index, line=idx_tok.line)
            elif self.current().type == '.' and self.peek().type == 'NAME':
                self.advance()
                field_tok = self.expect('NAME')
                node = Field(obj=node, field=field_tok.value, line=field_tok.line)
            else:
                break
        return node
    
    def primary(self):
        tok = self.current()
        
        if tok.type == 'NUMBER':
            self.advance()
            return Num(value=tok.value, line=tok.line)
        
        if tok.type == 'STRING':
            self.advance()
            return Str(value=tok.value, line=tok.line)
        
        if tok.type == 'KEYWORD':
            if tok.value == 'true':
                self.advance()
                return Bool(value=True, line=tok.line)
            if tok.value == 'false':
                self.advance()
                return Bool(value=False, line=tok.line)
            if tok.value == 'nil':
                self.advance()
                return Nil(line=tok.line)
            if tok.value == 'if':
                return self.if_expr()
            if tok.value == 'let':
                return self.let_expr()
            if tok.value == 'fn':
                return self.fn_expr()
            if tok.value == 'print':
                return self.print_expr()
        
        if tok.type == 'NAME':
            self.advance()
            # Check for function call
            if self.current().type == '(':
                self.advance()
                args = []
                if self.current().type != ')':
                    args.append(self.expr())
                    while self.current().type == ',':
                        self.advance()
                        args.append(self.expr())
                call_tok = self.expect(')')
                return Call(func=Name(name=tok.value, line=tok.line), args=args, line=call_tok.line)
            return Name(name=tok.value, line=tok.line)
        
        if tok.type == '[':
            self.advance()
            elements = []
            if self.current().type != ']':
                elements.append(self.expr())
                while self.current().type == ',':
                    self.advance()
                    if self.current().type == ']': break
                    elements.append(self.expr())
            list_tok = self.expect(']')
            return List(elements=elements, line=list_tok.line)
        
        if tok.type == '{':
            self.advance()
            pairs = []
            if self.current().type != '}':
                key = self.expr()
                self.expect(':')
                value = self.expr()
                pairs.append((key, value))
                while self.current().type == ',':
                    self.advance()
                    if self.current().type == '}': break
                    key = self.expr()
                    self.expect(':')
                    value = self.expr()
                    pairs.append((key, value))
            dict_tok = self.expect('}')
            return Dict(pairs=pairs, line=dict_tok.line)
        
        if tok.type == '(':
            self.advance()
            expr_val = self.expr()
            self.expect(')')
            return expr_val
        
        raise SyntaxError(f"Unexpected token {tok.type} at {tok.line}:{tok.col}")
    
    def if_expr(self):
        if_tok = self.expect('KEYWORD')  # 'if'
        cond = self.expr()
        self.expect('{')
        then_branch = self.expr()
        self.expect('}')
        self.expect('KEYWORD')  # 'else'
        self.expect('{')
        else_branch = self.expr()
        self.expect('}')
        return If(cond=cond, then_branch=then_branch, else_branch=else_branch, line=if_tok.line)
    
    def let_expr(self):
        let_tok = self.expect('KEYWORD')  # 'let'
        name_tok = self.expect('NAME')
        self.expect('=')
        value = self.expr()
        return Let(name=name_tok.value, value=value, line=let_tok.line)
    
    def fn_expr(self):
        fn_tok = self.expect('KEYWORD')  # 'fn'
        self.expect('(')
        params = []
        if self.current().type != ')':
            params.append(self.expect('NAME').value)
            while self.current().type == ',':
                self.advance()
                params.append(self.expect('NAME').value)
        self.expect(')')
        self.expect('{')
        body = self.expr()
        self.expect('}')
        return Fn(params=params, body=body, line=fn_tok.line)
    
    def print_expr(self):
        print_tok = self.expect('KEYWORD')  # 'print'
        value = self.expr()
        return Print(value=value, line=print_tok.line)

# ===== Environment =====
class Env:
    def __init__(self, parent=None):
        self.parent = parent
        self.vars = {}
    
    def define(self, name, value):
        self.vars[name] = value
    
    def get(self, name):
        if name in self.vars:
            return self.vars[name]
        if self.parent:
            return self.parent.get(name)
        return Miss(f"undefined variable: {name}")

# ===== Evaluator =====
class Fn:
    def __init__(self, params, body, closure_env):
        self.params = params
        self.body = body
        self.closure_env = closure_env
    
    def __repr__(self):
        return f"<fn({', '.join(self.params)})>"

def is_truthy(val):
    if isinstance(val, bool): return val
    if val is None: return False
    if isinstance(val, Miss): return False
    return True

def show(val):
    if val is None: return "nil"
    if isinstance(val, bool): return "true" if val else "false"
    if isinstance(val, (int, float)): return str(val)
    if isinstance(val, str): return f'"{val}"'
    if isinstance(val, list): return "[" + ", ".join(show(v) for v in val) + "]"
    if isinstance(val, dict): return "{" + ", ".join(f"{show(k)}: {show(v)}" for k,v in val.items()) + "}"
    if isinstance(val, Fn): return str(val)
    if isinstance(val, Miss): return f"miss({val.reason!r})"
    return str(val)

def evaluate(node, env):
    try:
        if isinstance(node, Num): return node.value
        if isinstance(node, Str): return node.value
        if isinstance(node, Bool): return node.value
        if isinstance(node, Nil): return None
        
        if isinstance(node, Name):
            return env.get(node.name)
        
        if isinstance(node, List):
            vals = [evaluate(e, env) for e in node.elements]
            for v in vals:
                if missed(v): return v
            return vals
        
        if isinstance(node, Dict):
            d = {}
            for k_node, v_node in node.pairs:
                k = evaluate(k_node, env)
                if missed(k): return k
                v = evaluate(v_node, env)
                if missed(v): return v
                # Convert list/dict keys to strings for dict keys
                key = show(k) if isinstance(k, (list, dict, Fn)) else k
                d[key] = v
            return d
        
        if isinstance(node, BinOp):
            left = evaluate(node.left, env)
            if missed(left): return left
            right = evaluate(node.right, env)
            if missed(right): return right
            
            if node.op == '+':
                if isinstance(left, (int, float)) and isinstance(right, (int, float)):
                    return left + right
                if isinstance(left, str) and isinstance(right, str):
                    return left + right
                if isinstance(left, list) and isinstance(right, list):
                    return left + right
                return Miss(f"cannot add {type(left).__name__} and {type(right).__name__}")
            
            if node.op == '-':
                if isinstance(left, (int, float)) and isinstance(right, (int, float)):
                    return left - right
                return Miss(f"cannot subtract {type(right).__name__} from {type(left).__name__}")
            
            if node.op == '*':
                if isinstance(left, (int, float)) and isinstance(right, (int, float)):
                    return left * right
                return Miss(f"cannot multiply {type(left).__name__} and {type(right).__name__}")
            
            if node.op == '/':
                if isinstance(left, (int, float)) and isinstance(right, (int, float)):
                    if right == 0: return Miss("division by zero")
                    return left / right
                return Miss(f"cannot divide {type(left).__name__} by {type(right).__name__}")
            
            if node.op == '%':
                if isinstance(left, int) and isinstance(right, int):
                    if right == 0: return Miss("division by zero")
                    return left % right
                return Miss(f"cannot modulo {type(left).__name__} by {type(right).__name__}")
            
            if node.op == '==': return left == right
            if node.op == '!=': return left != right
            if node.op == '<': return left < right if not isinstance(left, (dict, list, Fn)) else Miss("cannot compare")
            if node.op == '<=': return left <= right if not isinstance(left, (dict, list, Fn)) else Miss("cannot compare")
            if node.op == '>': return left > right if not isinstance(left, (dict, list, Fn)) else Miss("cannot compare")
            if node.op == '>=': return left >= right if not isinstance(left, (dict, list, Fn)) else Miss("cannot compare")
            
            if node.op == 'and':
                if not is_truthy(left): return left
                return right
            
            if node.op == 'or':
                if is_truthy(left): return left
                return right
        
        if isinstance(node, UnOp):
            operand = evaluate(node.operand, env)
            if missed(operand): return operand
            
            if node.op == 'not':
                return not is_truthy(operand)
            
            if node.op == '-':
                if isinstance(operand, (int, float)):
                    return -operand
                return Miss(f"cannot negate {type(operand).__name__}")
        
        if isinstance(node, Index):
            obj = evaluate(node.obj, env)
            if missed(obj): return obj
            index = evaluate(node.index, env)
            if missed(index): return index
            
            if isinstance(obj, list):
                if not isinstance(index, int): return Miss("list index must be int")
                if index < 0 or index >= len(obj): return Miss("list index out of range")
                return obj[index]
            
            if isinstance(obj, dict):
                key = show(index) if isinstance(index, (list, dict, Fn)) else index
                return obj.get(key, Miss("key not found"))
            
            if isinstance(obj, str):
                if not isinstance(index, int): return Miss("string index must be int")
                if index < 0 or index >= len(obj): return Miss("string index out of range")
                return obj[index]
            
            return Miss(f"cannot index {type(obj).__name__}")
        
        if isinstance(node, Field):
            obj = evaluate(node.obj, env)
            if missed(obj): return obj
            if not isinstance(obj, dict): return Miss(f"cannot access field on {type(obj).__name__}")
            return obj.get(node.field, Miss(f"field {node.field} not found"))
        
        if isinstance(node, Call):
            func = evaluate(node.func, env)
            if missed(func): return func
            if not isinstance(func, Fn): return Miss(f"cannot call {type(func).__name__}")
            
            args = [evaluate(a, env) for a in node.args]
            for arg in args:
                if missed(arg): return arg
            
            if len(args) != len(func.params):
                return Miss(f"function expects {len(func.params)} args, got {len(args)}")
            
            call_env = Env(func.closure_env)
            for param, arg in zip(func.params, args):
                call_env.define(param, arg)
            
            return evaluate(func.body, call_env)
        
        if isinstance(node, If):
            cond = evaluate(node.cond, env)
            if missed(cond): return cond
            if is_truthy(cond):
                return evaluate(node.then_branch, env)
            else:
                return evaluate(node.else_branch, env)
        
        if isinstance(node, Let):
            value = evaluate(node.value, env)
            if missed(value): return value
            env.define(node.name, value)
            return value
        
        if isinstance(node, Fn):
            return Fn(node.params, node.body, env)
        
        if isinstance(node, Print):
            value = evaluate(node.value, env)
            if missed(value):
                print(show(value))
                return value
            print(show(value))
            return value
    
    except RecursionError:
        return Miss("stack overflow")
    except Exception as e:
        return Miss(str(e))

# ===== Main =====
if __name__ == '__main__':
    if len(sys.argv) < 2:
        print("Usage: python3 zeph.py <file>", file=sys.stderr)
        sys.exit(2)
    
    try:
        with open(sys.argv[1]) as f:
            src = f.read()
    except FileNotFoundError:
        print(f"Error: {sys.argv[1]} not found", file=sys.stderr)
        sys.exit(2)

    if tokens is None:
        print("Error: lexer error", file=sys.stderr)
        sys.exit(2)

        parser = Parser(tokens)
        exprs = parser.parse()
    except SyntaxError as e:
        print(f"Error: {e}", file=sys.stderr)
        sys.exit(2)
    
    env = Env()
    result = None
    for expr in exprs:
        result = evaluate(expr, env)
        if missed(result):
            print(f"Error: {result.reason}", file=sys.stderr)
            sys.exit(1)
    
    sys.exit(0)
```

```markdown
# Zephyr Language Specification

## Core Idea
A simple, expression-oriented scripting language with first-class functions, immutable data (lists, dicts), and error propagation as values.

## Design Decisions
- **Errors as values**: `Miss(reason)` propagates through all operations
- **Expression-oriented**: everything returns a value
- **Newline-terminated**: statements separated by newlines (bracket nesting suppressed)
- **Strict, left-to-right evaluation**
- **Immutable data structures**
- **First-class functions** capturing lexical environment

## Grammar (precedence: low→high)
```
program := expr* EOF
expr := or_expr
or_expr := and_expr ('or' and_expr)*
and_expr := comparison ('and' comparison)*
comparison := add_expr (('=='|'!='|'<'|'<='|'>'|'>=') add_expr)*
add_expr := mul_expr (('+'|'-') mul_expr)*
mul_expr := unary (('*'|'/'|'%') unary)*
unary := ('not'|'-') unary | postfix
postfix := primary ('[' expr ']' | '.' NAME)*
primary := NUMBER | STRING | 'true' | 'false' | 'nil' | NAME
          | '[' expr_list? ']' | '{' dict_pairs? '}'
          | '(' expr ')' | if_expr | let_expr | fn_expr | print_expr

if_expr := 'if' expr '{' expr '}' 'else' '{' expr '}'
let_expr := 'let' NAME '=' expr
fn_expr := 'fn' '(' param_list? ')' '{' expr '}'
print_expr := 'print' expr
```

## Error Story
- `Miss(reason)` is first-class: unbound name, bad index, arity, div-by-zero, non-bool condition
- All operations propagate Miss (operand is Miss ⇒ result is Miss)
- No exceptions; errors flow as values

## Exit Codes
- 0: success
- 1: runtime error (Miss value produced)
- 2: lex/parse error
```
