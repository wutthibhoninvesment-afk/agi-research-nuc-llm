```markdown
A functional expression language with first-class functions, immutable data structures, and errors-as-values propagation. Designed for clarity and total evaluation—every program terminates and returns a value, never raising exceptions.

## Error Handling
Errors propagate as `Miss` values with reason strings. All runtime faults convert to Miss: unbound names, type mismatches, division by zero, bad list indices. A `missed(x)` predicate tests if x is an error. Rescue operator `x ?? y` returns y if x is a Miss, otherwise x.
```

```markdown
# Calc Language Specification

## Core Idea
Functional expression language with first-class functions, immutable values, and errors-as-values (no exceptions).

## Design Decisions
1. **Errors propagate as values**: every operation returns a value or Miss error
2. **Total evaluation**: all programs terminate and return a value
3. **First-class functions**: functions as values, closures capture environment
4. **Immutable data**: lists and strings are immutable
5. **Strict evaluation**: eager argument evaluation

## Grammar (low to high precedence)
```
program    := expr EOF
expr       := let_expr | if_expr | or_expr
let_expr   := "let" NAME "=" expr "in" expr
if_expr    := "if" or_expr "then" expr "else" expr
or_expr    := and_expr ("or" and_expr)*
and_expr   := eq_expr ("and" eq_expr)*
eq_expr    := cmp_expr (("==" | "!=") cmp_expr)*
cmp_expr   := add_expr (("<" | ">" | "<=" | ">=") add_expr)*
add_expr   := mul_expr (("+" | "-") mul_expr)*
mul_expr   := unary_expr (("*" | "/" | "%") unary_expr)*
unary_expr := ("-" | "not") unary_expr | postfix_expr
postfix_expr := primary ("[" expr "]" | "(" args? ")")*
primary    := NUMBER | STRING | "true" | "false" | NAME | "[" list? "]" | "(" expr ")" | "fn" params "=>" expr
list       := expr ("," expr)*
params     := NAME ("," NAME)*
args       := expr ("," expr)*
```

## Built-in Functions
- `len(x)` — length of list or string
- `print(x)` — print and return x
- `type(x)` — type name as string
- `range(n)` — list [0, 1, ..., n-1]
- `map(fn, list)` — apply fn to each element
- `filter(fn, list)` — keep elements where fn(x) is true
- `fold(fn, init, list)` — reduce left to right

## Error Handling
- `missed(x)` — true if x is an error
- `x ?? y` — rescue operator: y if x is error, else x

## Exit Codes
- 0: success
- 1: program error (Miss value printed)
- 2: parse/lex error
```
