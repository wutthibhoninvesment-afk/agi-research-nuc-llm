# SPEC.md - Calc Language Specification

## Overview
Calc is a simple but complete scripting language with arithmetic, variables, functions, conditionals, and basic data structures (lists, records). It emphasizes clarity and totality - all errors are values, not exceptions.

## Design Decisions
1. **Error-as-value**: All runtime errors propagate as `Miss` values, never exceptions. No special error type - missing conditions, unbound names, type mismatches all become retrievable miss values.
2. **Immutable semantics**: All values are immutable. Variables are bindings, not references.
3. **Lexical scope with closures**: Functions capture their defining environment.
4. **Simple syntax**: No special symbols beyond what's necessary; familiar operators.

## Grammar (precedence ladder, low to high)
```
program   := stmt_list
stmt_list := stmt (NEWLINE stmt)* NEWLINE?
stmt      := LET NAME ASSIGN expr
           | expr
expr      := or_expr
or_expr   := and_expr (OR and_expr)*
and_expr  := eq_expr (AND eq_expr)*
eq_expr   := cmp_expr ((EQ | NE) cmp_expr)*
cmp_expr  := add_expr ((LT | LE | GT | GE) add_expr)*
add_expr  := mul_expr ((PLUS | MINUS) mul_expr)*
mul_expr  := unary_expr ((STAR | SLASH | PERCENT) unary_expr)*
unary_expr := (NOT | MINUS) unary_expr | postfix_expr
postfix_expr := primary (LPAREN args RPAREN | LBRACKET expr RBRACKET | DOT NAME)*
primary   := NUMBER | STRING | NAME | TRUE | FALSE | NULL
           | LPAREN expr RPAREN
           | LBRACKET (expr (COMMA expr)*)? RBRACKET
           | LBRACE (record_field (COMMA record_field)*)? RBRACE
           | IF expr THEN expr ELSE expr
           | FN LPAREN params RPAREN LBRACE stmt_list RBRACE
record_field := NAME COLON expr
params    := (NAME (COMMA NAME)*)?
args      := (expr (COMMA expr)*)?
```
