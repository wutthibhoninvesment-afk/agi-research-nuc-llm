```markdown
# Calc Language Specification

## Overview
Calc is a simple expression-based scripting language with variables, functions, and control flow.

## Design Decisions
- Errors propagate as values (no exceptions)
- Newlines separate statements unless inside parentheses
- Operators have standard precedence (arithmetic > comparison > logical)
- Functions are first-class values

## Grammar (Low to High Precedence)
1. Assignment: `let x = expr`
2. Logical OR: `x or y`
3. Logical AND: `x and y`
4. Comparison: `==`, `!=`, `<`, `>`, `<=`, `>=`
5. Addition/Subtraction: `+`, `-`
6. Multiplication/Division: `*`, `/`, `%`
7. Unary: `-`, `not`
8. Primary: literals, names, `(expr)`, `[...]`, `if/else`, `fn`, function calls

## Types
- Number (int/float)
- String
- Boolean
- List
- Function
- Error (propagating value)

## Exit Codes
- 0: success
- 1: program-level error (unbound name, type error, etc.)
- 2: lex/parse error
```
